Circular Input Demo

Focused demos for the sector geometry input and its decoration editor.

Circular Input

Click a sector to bring its overlapped radius and height handles to the front. Drag the start or end boundary handles to redistribute values, then use the fields below as the source of truth for sector values, radiuses, heights, gap, and border radius.

Circular Decoration Input

Select sectors to edit their fill and stroke. Use Shift, Ctrl, or Cmd to toggle multiple sectors. The paint forms stay visible, disable when nothing is selected, and clicking the selected sector again clears selection.

Circular Text Input

Select sectors to edit their text, anchor, point or path mode, offsets, and SVG text attributes. Use Shift, Ctrl, or Cmd to edit multiple sectors at once.
