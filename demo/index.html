Number Aware Input

This element is back to numeric token editing only. Place the caret inside a number, then use arrow up/down or the inline controls to adjust just that numeric token.

Basic token stepping

Pair lock keeps adjacent values in ratio during stepping, while direct edits stay independent by default

Use pair-lock-mode="all" when direct edits should also update the pair

Readonly text allows numeric-only editing

Readonly number protects numeric tokens while text stays editable

Multiline number-aware editing

Comma decimals are opt-in with decimal-separator=","; by default, 101,206 is treated as two numeric tokens.

Token Aware Input

This element edits constrained string tokens. It can target the whole value or a single capture group inside a pattern, then step or suggest from a known list.

Whole-value constrained list cycling

Pattern-aware resolution token constrained to known values

Pattern-aware honorific token inside surrounding text

Combined Stage

This stage lets selection-box manage selection while drag-box and transform-box keep handling movement and transforms. Plain click picks one item, Shift+click adds more selections, and movement only starts after an item is already selected.

These buttons sit outside the stage and move the currently selected items in x and y.
