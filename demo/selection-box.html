Selection Box Standalone Demo

This standalone page focuses only on selection-box. The stage is fixed at 800x600 and contains three direct selectable children: an image, an inline SVG, and a regular HTML article.

Click to single-select, Shift+click to add or remove more items, or drag from empty space to marquee-select. Clicking empty space clears the current selection.

HTML Editorial Card

This card is regular semantic HTML. It participates in selection exactly like the bitmap image and the inline SVG because each item is a direct child of the selection-box.
